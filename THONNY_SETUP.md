# Thonny setup (XIAO ESP32-S3)

1. Install **MicroPython** on the board (Thonny → *Configure interpreter*).
2. Copy **`main.py`** and **`gyroscope.py`** to the MicroPython device.
3. Run **`main.py`**.

Pin wiring is documented in **`DOCUMENTATION.md`**.

Only edit pins in **`main.py`** (top section).
